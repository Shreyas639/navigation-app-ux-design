# Navigation App — UX Design & Prototyping

Coursework for Middlesex University (2025).

## What it does
Full UX design process for a mobile navigation and transportation 
app, from user research through to high-fidelity prototype.

## Design Process
- User research and two distinct personas (urban professional and rural user)
- User stories mapped to app features
- Cognitive psychology principles applied to UI decisions:
  - Chunking theory — simplified information display
  - Stroop effect — consistent colour and label pairing
  - Post-completion error — confirmation screens after key actions
- Low to high fidelity wireframes
- Moderated usability testing using Think Aloud Protocol
- Quantitative evaluation using SUS (System Usability Scale) scores
  and task completion rates

## Key Features Designed
- Real-time navigation
- Offline mode for low connectivity areas
- Calendar and work tool integration
- Location sharing
